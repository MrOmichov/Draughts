# Русские шашки для Android

Мой ранний Android-проект на Java: шашки для двух игроков на одном устройстве, игра с компьютером и несколько учебных позиций. Интерфейс сделан на Android Views и XML-разметке.

## Что есть

- Доска 8×8, выбор шашки и подсветка доступных клеток.
- Обычные ходы, обязательное взятие, продолжение серии взятий и превращение в дамку.
- Локальная игра вдвоём.
- Компьютерный соперник с оценкой позиции по материалу и расположению шашек.
- Пять учебных заданий с заданными позициями и пояснениями.

Это учебная реализация, а не готовый шашечный движок. Бот использует собственную эвристику; полноценного поиска minimax в проекте нет.

## Запуск

Нужны Android Studio, JDK 11 и установленный Android SDK 33. В проекте используются Android Gradle Plugin 7.4.2 и Gradle Wrapper 7.5. Минимальная версия Android — 5.0 (API 21).

Откройте корень репозитория в Android Studio, дождитесь синхронизации Gradle и запустите модуль `app` на устройстве или эмуляторе.

Сборка debug APK из терминала:

```bash
./gradlew assembleDebug
```

В Windows:

```powershell
.\gradlew.bat assembleDebug
```

Результат сборки: `app/build/outputs/apk/debug/app-debug.apk`. В `app/debug` также лежит ранее собранный APK; он может отличаться от текущих исходников.

## Управление

В меню выберите игру с человеком, с компьютером или обучение. Нажмите на свою шашку, затем на подсвеченную клетку. Если доступно взятие, обычный ход не предлагается; при серии взятий нужно продолжать ход той же шашкой.

## Как устроен код

- `MainActivity` — игра вдвоём.
- `BotActivity` — игра с компьютером и оценка позиции.
- `ExActivity` и `LevelActivity` — выбор заданий и учебные позиции.
- `MenuActivity` — главное меню.

Доска хранится в двумерном массиве. Проверка ходов и обновление интерфейса находятся в Activity; часть логики между режимами повторяется. Проект оставлен в этой структуре как пример ранней работы с Java и Android.

## Ограничения

Нет сетевой игры и сохранения партии. В репозитории оставлены стандартные примерные тесты Android Studio — правила шашек ими не проверяются. Корректность всех игровых ситуаций и сборка на современных версиях Android Studio отдельно не подтверждены.
